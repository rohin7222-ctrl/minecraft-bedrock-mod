## 🎮 பயன்படுத்தும் முறை (How to Use):

### வழிமுறை 1: Android App வழியாக (1-Click Launch)
1. GitHub Releases-லிருந்து **`app-debug.apk`**-ஐ download செய்து install செய்யவும்.
2. App-ஐ திறந்து, மேலே உள்ள தேடல் பெட்டி அல்லது வகைத் தேர்வுகளைப் பயன்படுத்தி நீங்கள் விரும்பும் Mod-ஐ எளிதாகக் கண்டறியவும்.
3. Mod-ன் பட்டனைத் தொடவும் (எ.கா. `IMPORT BEN 10 V6`, `IMPORT DEMON SLAYER`).
4. Minecraft PE தானாகவே திறந்து Add-on import ஆகிவிடும்!

### வழிமுறை 2: நேரடி Addon Download (.mcaddon)
1. GitHub Releases பக்கத்திலிருந்து எந்தவொரு **`.mcaddon`** கோப்பையும் நேரடியாக பதிவிறக்கலாம்.
2. பதிவிறக்கிய கோப்பை ஒருமுறை tap செய்தாலே Minecraft Bedrock தானாகத் திறந்து Addon-ஐ import செய்துவிடும்!
